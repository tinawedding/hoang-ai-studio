# HN AI VOICE STUDIO PRO

Ứng dụng web đang được xây dựng: tải video lên máy chủ, đổi tông và làm sạch âm thanh, xem trước và xuất MP4 H.264/AAC.

Trạng thái: mã nguồn đang được chuẩn bị; chưa triển khai lên Render. Không có dữ liệu video hoặc thông tin đăng nhập trong kho mã.

Đợt đầu tập trung vào luồng video thực. Hiệu ứng âm thanh dùng DSP/FFmpeg; chưa tích hợp mô hình AI chuyển danh tính giọng. File yêu cầu đính kèm trong cuộc trò chuyện chưa đọc được do phiên làm việc thiếu quyền công cụ đọc file cục bộ, nên cần đối chiếu yêu cầu sau.
